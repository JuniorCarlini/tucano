Slider

Un solo valor, o un rango con mínimo y máximo. Los dos son el <input type="range"> nativo con otro diseño — en el rango, dos de ellos sobre la misma pista. El name, el POST, el reset, las flechas y el anuncio del lector de pantalla siguen siendo los del navegador; el script pinta el tramo elegido, impide que el mínimo pase del máximo y escribe el valor.

Ejemplos

El mismo <input>, con otros atributos.

Los decimales del texto salen del step: con 0.5, uno.

Edad

Junto a un campo

La caja tiene la altura de un campo, con la pista en el medio: la línea no se desalinea.

Desactivado

Cómo usar

Slider simple: la clase y el atributo en el propio <input>. Rango: un contenedor con dos, y cada uno envía con su propio name.

Los dos extremos necesitan el mismo min, max y step. El formulario recibe price_min=800&price_max=3200 — en un filtro por GET, la URL vuelve rellenada. data-output indica dónde aparece el valor escrito; data-currency lo escribe como dinero, y los decimales salen del step: paso 1 escribe "800 €", y no "800,00 €".

Por qué la clase viene de la plantilla

Así el slider nace con la altura y la pista correctas en el primer cuadro, sin salto cuando llega el JavaScript. Sin script funciona y envía; solo el tramo elegido queda sin el color de acento.

Con Django

El widget del slider simple es un NumberInput con otro type. El rango son dos campos, dibujados dentro del mismo contenedor.

class RangeInput(forms.NumberInput):
    input_type = "range"

class ProductFilter(forms.Form):
    attrs = {"min": 0, "max": 5000, "step": 50}
    price_min = forms.IntegerField(initial=0, widget=RangeInput(attrs=attrs))
    price_max = forms.IntegerField(initial=5000, widget=RangeInput(attrs=attrs))

En JavaScript

const price = new Tucano.Slider('#price-range', {
  currency: 'EUR',
  output: '#price',
  onChange: ([min, max]) => console.log(min, max),
});

price.getValue();                        // [800, 3200]
price.setValue([1000, 2000]);            // ordena el par y emite una vez
price.setValue([0, 5000], { silent: true });

new Tucano.Slider('#rating', {
  format: (value) => `${value} estrellas`,  // gana sobre currency
});

Al arrastrar, como en el color picker, tucano:change sale con cada movimiento — lo que sirve a una vista previa en vivo — y el change nativo una sola vez, al soltar: es el que deben escuchar el hx-trigger y el filtro del formulario. Con el teclado, los dos salen con cada tecla.

document.addEventListener('tucano:change', (e) => {
  if (!e.target.matches('.tuc-slider')) return;
  e.detail.value;      // número en el simple, [mínimo, máximo] en el rango
  e.detail.instance;   // el Slider
});

Teclado y accesibilidad

El teclado es el del <input type="range"> nativo, en cada extremo. En el rango, cada extremo es una parada del Tab.

TeclaAcción
← → ↑ ↓Un step hacia cada lado
PageUp PageDownUn paso mayor, del navegador
Home EndEl mínimo y el máximo — en el rango, hasta el otro extremo

Cada extremo recibe aria-valuetext con el valor escrito, y el lector de pantalla dice "800 €" en vez de "800". En el rango, el extremo sin etiqueta recibe un nombre propio — "Mínimo" y "Máximo" por defecto, cambiados con Tucano.setTexts({ slider: … }). En el rango el puntero lo maneja el componente: un clic en la pista mueve el extremo más cercano, y con los dos en el mismo lugar el primer movimiento decide cuál se mueve.
