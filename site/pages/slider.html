Slider

Um valor só, ou um intervalo com mínimo e máximo. Os dois são o <input type="range"> nativo com o desenho trocado — no intervalo, dois deles sobre a mesma trilha. O name, o POST, o reset, as setas e o anúncio do leitor de tela continuam sendo os do navegador; o script pinta o trecho escolhido, impede o mínimo de passar do máximo e escreve o valor por extenso.

Exemplos

O mesmo <input>, com atributos diferentes.

Passo decimal

As casas do texto saem do step: com 0.5, uma casa.

Intervalo sem rótulo nas pontas

Sem <label> nem aria-label, as pontas ganham "Mínimo" e "Máximo".

Idade

Ao lado de um campo

A caixa tem a altura de um campo, com a trilha no meio: a linha não desalinha.

Desativado

disabled no nativo; no intervalo, nos dois.

Como usar

Slider simples: a classe e o atributo no próprio <input>. Intervalo: um contêiner com dois, e cada um posta com o próprio name.

As duas pontas precisam do mesmo min, max e step. O formulário recebe price_min=800&price_max=3200 — num filtro por GET, é a URL que volta preenchida. data-output aponta onde o valor aparece escrito; data-currency escreve como dinheiro, e as casas saem do step: passo 1 escreve "R$ 800", e não "R$ 800,00".

Por que a classe vem do template

Assim o slider nasce com a altura e a trilha certas no primeiro quadro, sem pulo quando o JavaScript chega. Sem script ele funciona e posta; só o trecho escolhido fica sem a cor de destaque.

Com Django

O widget do slider simples é um NumberInput com outro type. O intervalo são dois campos, desenhados dentro do mesmo contêiner.

class RangeInput(forms.NumberInput):
    input_type = "range"

class ProductFilter(forms.Form):
    attrs = {"min": 0, "max": 5000, "step": 50}
    price_min = forms.IntegerField(initial=0, widget=RangeInput(attrs=attrs))
    price_max = forms.IntegerField(initial=5000, widget=RangeInput(attrs=attrs))

Em JavaScript

const price = new Tucano.Slider('#price-range', {
  currency: 'BRL',
  output: '#price',
  onChange: ([min, max]) => console.log(min, max),
});

price.getValue();                        // [800, 3200]
price.setValue([1000, 2000]);            // ordena o par e emite uma vez
price.setValue([0, 5000], { silent: true });

new Tucano.Slider('#rating', {
  format: (value) => `${value} estrelas`,  // vence o currency
});

No arrasto, como no color picker, tucano:change sai a cada movimento — é o que serve a uma prévia ao vivo — e o change nativo uma vez só, ao soltar: é ele que o hx-trigger e o filtro do formulário devem ouvir. Pelo teclado, os dois saem a cada tecla.

document.addEventListener('tucano:change', (e) => {
  if (!e.target.matches('.tuc-slider')) return;
  e.detail.value;      // número no simples, [mínimo, máximo] no intervalo
  e.detail.instance;   // o Slider
});

Teclado e acessibilidade

O teclado é o do <input type="range"> nativo, em cada ponta. No intervalo, cada ponta é uma parada do Tab.

TeclaAção
← → ↑ ↓Um step para cada lado
PageUp PageDownUm passo maior, do navegador
Home EndO mínimo e o máximo — no intervalo, até a outra ponta

Cada ponta recebe aria-valuetext com o valor escrito, e o leitor de tela diz "R$ 800" em vez de "800". No intervalo, a ponta sem rótulo ganha "Mínimo" ou "Máximo" (Tucano.setTexts({ slider: … }) troca). No intervalo o ponteiro é tratado pelo componente: o clique na trilha leva a ponta mais perto, e com as duas no mesmo lugar o primeiro movimento decide qual se move.
