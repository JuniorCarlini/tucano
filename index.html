Tucano

Date picker, select com busca e color picker para formulários. Sem dependências em runtime. Estilos escritos em Tailwind e distribuídos já compilados — o projeto que consome não precisa de build.

15 KB JS gzip 4 KB CSS gzip 0 dependências Sem preflight do Tailwind Nativo no celular

Instalação

Dois arquivos e nada mais. Funciona com HTML puro, sem npm e sem build.

<!-- CDN -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/tucano@0.2.0/dist/tucano.min.css">
<script src="https://cdn.jsdelivr.net/npm/tucano@0.2.0/dist/tucano.min.js" defer></script>

npm

npm install tucano
import { DatePicker, Select, ColorPicker } from 'tucano';
import 'tucano/css';
Prenda a versão. @latest no jsDelivr fica muito tempo em cache e serve build antigo sem avisar.

Depois disso, qualquer elemento com data-tuc-* é inicializado sozinho — inclusive o que chegar depois por swap do HTMX.

Date picker

Data, período, hora e data+hora. Campo com máscara, calendário navegável por mês e ano, e no celular ele troca sozinho pelo seletor nativo do sistema.

Como usar

<input type="text" name="data" data-tuc-datepicker>
<input type="text" name="quando" data-tuc-datepicker data-time="true">
<input type="text" name="periodo" data-tuc-datepicker data-mode="range">
No celular data e data+hora viram o seletor nativo do sistema — a roda do iOS, o diálogo do Android. Período continua no painel porque não existe seletor de intervalo nativo em HTML. O valor que chega no servidor é idêntico nos dois caminhos.

Select

Enriquece um <select> nativo. O elemento original continua no DOM guardando o valor, então name, multiple e required seguem funcionando.

Como usar

<select name="uf" data-tuc-select>
  <option value="">Selecione...</option>   <!-- vira placeholder -->
  <option value="SP">São Paulo</option>
</select>

<select name="tags" data-tuc-select multiple data-placeholder="Adicione...">
A busca ignora acentos: sao encontra "São Paulo". O campo tem altura fixa e linha única de propósito — com tags quebrando linha ele cresceria e desalinharia o formulário. O excesso rola na horizontal.

Color picker

Área HSV, matiz, opacidade, paleta e conta-gotas. Aceita hex de 3, 4, 6 e 8 dígitos, rgb(), rgba(), hsl() e hsla().

Como usar

<input type="text" name="cor" value="#4f46e5" data-tuc-color>
<input type="text" name="marca" data-tuc-color data-alpha="false"
       data-swatches="#0a0a0a,#ea580c,#16a34a">
O estado interno é HSVA, não RGB: converter a cada movimento perderia a matiz quando a saturação chega a zero — todo cinza viraria vermelho ao clarear.

Django

O campo visível mostra a data no formato do locale; um <input type="hidden"> com o mesmo name carrega o valor em ISO. É esse que chega no request.POST.

No formulário

class EventoForm(forms.ModelForm):
    class Meta:
        widgets = {
            "data_evento": forms.TextInput(attrs={"data-tuc-datepicker": "", "data-time": "true"}),
            "uf": forms.Select(attrs={"data-tuc-select": ""}),
            "tags": forms.SelectMultiple(attrs={"data-tuc-select": ""}),
            "cor": forms.TextInput(attrs={"data-tuc-color": ""}),
        }

O que chega no servidor

data_evento = 2026-12-25T09:30     # DateTimeField faz o parse direto
periodo     = 2026-03-01,2026-03-15
tags        = django                # request.POST.getlist("tags")
tags        = htmx
cor         = #4f46e5
HTMX já está coberto. A lib re-inicializa sozinha no htmx:afterSwap, então campos que chegam por swap funcionam sem você fazer nada.

Tema

Toda cor, raio e sombra passa por variável CSS. Trocar o visual é sobrescrever variável — não precisa recompilar nada.

Experimente trocar a cor de destaque desta página 
.tuc-dp, .tuc-select, .tuc-select__menu, .tuc-color-field, .tuc-colorpicker {
  --tuc-accent: #0d9488;
  --tuc-radius: 1rem;
  --tuc-cell: 2.5rem;   /* tamanho do dia no calendário */
}
VariávelPara quê
--tuc-accentCor de destaque: dia selecionado, tags, check
--tuc-accent-softFaixa do intervalo, fundo das tags
--tuc-bg --tuc-fgFundo e texto dos painéis
--tuc-muted --tuc-subtleTextos secundários
--tuc-border --tuc-hoverLinhas e estado de hover
--tuc-radiusRaio dos painéis
--tuc-cellTamanho da célula de dia
--tuc-durationDuração das transições
Escuro segue a classe .dark no <html>, convenção do Tailwind. Para seguir o sistema operacional, use <html data-tuc-theme="auto"> — é opt-in de propósito, para o componente não escurecer sozinho numa página clara.

Referência

Todos emitem tucano:change, que borbulha — use isso quando não controlar a ordem de inicialização.

document.addEventListener('tucano:change', (e) => {
  console.log(e.target.name, e.detail.value, e.detail.iso);
});

const dp = new Tucano.DatePicker('#entrega', {
  mode: 'range', time: true, minuteStep: 15,
  disabledDates: (d) => d.getDay() === 0,
});

const s = new Tucano.Select('#uf', { maxItems: 3 });
s.refresh();  // depois de trocar as <option> por HTMX

const c = new Tucano.ColorPicker('#cor', { format: 'rgb' });
c.getRgb();   // { r, g, b, a }
